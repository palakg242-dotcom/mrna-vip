# Week 1 - Model comparison (Logistic Regression vs Random Forest)

Logistic Regression performed better on the held-out test set (100 patients), with a High-risk F1 of 0.70 and accuracy of 0.72, versus 0.64 and 0.65 for Random Forest, so it was selected and saved as `outputs/risk_model.joblib`. Because 100 test rows is a small sample, I confirmed the gap with 5-fold cross-validation on all 500 rows: mean F1 was 0.72 for Logistic Regression and 0.64 for Random Forest, so the ranking is not an accident of one split. A likely reason is that the dataset is small (400 training rows) and noisy, and every feature (biomarker level, number of conditions, dose, age, prior reactions) pushes risk in a roughly additive way, which a linear model captures with few parameters; 200 deep trees can instead fit noise in the training rows. This is a hypothesis, not something I tested directly. Neither model is excellent (about 0.65-0.72 accuracy), which fits the PRD's note that the signal in the data is noisy by design.
